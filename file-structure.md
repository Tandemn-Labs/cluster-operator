# File structure notes

Notes on what files do what, since many are auto-generated by kubebuilder.

## CRDs
- `api/v1alpha1/clusterplan_types.go` - Main definition for ClusterPlan CRD, has structs like `ClusterPlan, ClusterPlanSpec, ClusterPlanStatus`
- `api/v1alpha1/groupversion_info.go` - Defines the `planner.tandemn.com/v1alpha1` GV and scheme registration
- `config/crd/bases/... .yaml` - The actual generated CRD
- `config/samples/planner... .yaml` - A sample of what an instance of ClusterPlan looks like

## Operator
- `cmd/main.go` - Main entry point for the operator program. Registers our new ClusterPlan scheme, makes the manager.
- `internal/controller/clusterplan_controller.go` - Actually implements the `ClusterPlanReconciler` struct and the `Reconcile` function. The `SetupWithManager` function registers the Kind(s) that we watch for

## Others
- `config/rbac/role.yaml` - ClusterRole for the operator itself
